## مهم
- **لا تغيّر أسماء المجلّدات**: التطبيق يفتح الألعاب القديمة بهذه الأسماء.
- مجلّد `shared` مشترك بين كل الألعاب (الألوان، الأصوات، الأزرار) — لا تحذفه.
- لتعديل بيانات لعبة: افتح ملف `data.js` من موقع GitHub، اضغط القلم ✏️، عدّل، ثم Commit.
- `tools/export.html`: ينزّل بياناتك القديمة من Firebase كملفات `data.js` جاهزة (مرة واحدة عند النقل).

## إضافة لعبة جديدة
1. أنشئ مجلّداً جديداً فيه `index.html` (يمكن نسخ لعبة موجودة كقالب).
2. في التطبيق: لوحة الأدمن ← المحتوى ← المكتبة ← عنصر جديد ← النوع «لعبة» ← الصق الرابط واختر الصف والفصل.
